The owner's objective is to operate reliably in consumer installations for **at least two years**, building trust before a larger successor release. A design document or unit-test suite **cannot guarantee two incident-free years**; prove containment, recoverability, compatibility and observability instead.

- **P0 before alpha:** Installed-profile upgrade/rollback tests (previous REDOWN and current Click2Cloud), preserved extension identity/OAuth redirect/native menu, real Windows Chrome + Edge checks where claimed, verification of real cloud bytes/receipt; failure injection in optional Basic/History/diagnostics, quota, restart and partial writes; 100k/1m synthetic History display memory tests; independent complete two-file History exports and two-file RAW diagnostic exports; 512 MiB Basic export stress with cancellation/low-RAM handling or documented supported limit. No deployed release or migration before GO gates.
- **P1 before widespread/stable release:** Endurance soak (repeated saves, history browsing, restarts, export/cancel, account reconnect), weekly/monthly storage-health checks, abandoned forensic snapshot GC, writer retry health metrics, provenance/redaction tests, and Chrome/Edge MV3 suspension/regeneration tests. Reproduce suspected resource leaks over repeated use; measure heap/storage rather than infer.
- **Operational discipline:** Semantically versioned adapter/export contracts, additive migrations only with explicit reversible rollback, release notes and reproducible artifacts, staged rollout with early failure monitoring and ability to disable Basic-only integration without removing user data. Track OAuth/provider API/browser changes, response-code drift, and support issues; schedule compatible updates instead of promising a frozen two-year binary.
- **Persistence/recovery:** No automatic deletion of original History, no data overwrite across providers, no misleading verified statuses, no new Cloudflare migration. Back up/restore established configuration where supported; verify read-only index rebuild, recovery after partial failures and each provider's independent history still readable after rollback.
- **Shipping principle:** Deliver the smallest safe surface area first. Visual polish is not permission to replace a proven engine or couple diagnostic/History failures to saving.
