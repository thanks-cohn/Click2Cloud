## Stress measurements

`verification.json` includes isolated Node RSS and p50, p95 and p99 timings for the native callback fixtures. The screenshot fixture used a 290-byte PNG. The production encoded-image length check rejects data above the configured 12 MiB PNG budget before decoding. The application keeps two screenshot slots, three upload tasks per slot and 32 remote save transport slots. Busy screenshot commands are reported without queuing a future capture. Chromium's own capture allocation and Windows process RSS need separate measurement.
