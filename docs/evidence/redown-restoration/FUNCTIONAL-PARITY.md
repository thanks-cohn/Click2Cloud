## Severe reference defects deliberately not inherited

The paired extracted actual REDOWN Worker functions demonstrate its overescaped private-address guard and unchecked redirect userinfo; these are code-level reproductions, not claimed live exploits. The generic native fetch model is reused while retaining stronger checks. Whole-file unknown-length arrays and the arbitrary 300MiB default are not copied. Native Cloudflare/R2 service constraints remain: final single PUT has a 5GiB limit; transfers beyond it need a multipart final-writer implementation. Public-link guesses and post-failure “success” are not substituted for independent verification. R2 deletion cannot guarantee atomic moves against concurrent external clients.
