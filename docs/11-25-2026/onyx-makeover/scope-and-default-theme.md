# Makeover scope and default theme

Owner instructions — November 25, 2026.

- Oceania is the default theme until the owner explicitly approves the new Onyx design for production as the default. Preserve existing users' selected themes. Do not automatically migrate them to Onyx.
- Onyx may be selectable for testing; design reference approval is not approval to change the default theme.
- Files and File Explorer must remain unchanged, including layout, styling, controls and functionality.
- Remotes and Queue have approved visual directions. History is limited to the timestamp and URL disclosure corrections in history-targeted-corrections.md. All other pages remain outside the makeover scope until explicitly approved.
- Zero-flash initialization is mandatory across supported themes. Scope styling carefully to avoid regressions on unchanged pages. Preserve existing engine behavior and settings.
