# Optional provider-targeted projectile
Only visual-feedback code and the existing acceptance callback's provider argument changed. Actual accepted right-click destination selects one of four provider cards. Query the live matching window's visible Shelf, never a regular app tab, using a single bounded 60 ms request. No cached geometry, polling, additional cloud requests, or receipt/storage changes. Use visible card center relative to Shelf viewport, map to top webpage viewport fraction; browser UI boundaries, zoom or viewport differences can prevent pixel-perfect alignment. If closed, scrolled out, hidden, another tab/view, modal, unknown provider, timeout or cross-origin frame, preserve original endpoint. Existing randomized style, side choice, caps, reduced-motion, deduplication and acceptance timing remain intact; only the visual dispatch may wait up to 60 ms. No additional shelf animation. Focused tests: node --test tests/projectile-target.test.mjs. Actual Chrome alignment and multi-window behavior require live verification.
