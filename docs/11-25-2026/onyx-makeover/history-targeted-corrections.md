# History — approved targeted corrections

Owner approval: November 25, 2026.

History is NOT approved for a full makeover. Preserve existing layout, styling, controls, behavior, data and functionality except for the following two changes.

## Timestamp
Keep the timestamp in the top-right corner of each History card. Right-align two separate lines: date in existing M/D/YYYY format (example: 11/25/2026), followed by time in existing 12-hour format including seconds (example: 2:57:16 PM). No comma between date and time. Preserve underlying timestamp, timezone and existing chronological behavior.

## URLs
Use a single expandable labeled `URLs`. Expanding it immediately displays `Public URLs` (all existing public URL entries) and `Host URL` together. No secondary expandables or additional disclosure clicks. Preserve existing source URL metadata and access to any existing source URL fields; do not delete or silently relabel source URLs as public URLs. Keep existing copy/link actions and actual values. Do not fabricate missing URLs. Retain existing default disclosure behavior where possible.

## Scope and verification
Do not otherwise redesign History. Preserve Download, search, filtering, receipts, persistence, and all transfer-engine behavior. Verify multiple public URLs, missing URL data, long URLs, date/time rendering, narrow Shelf widths and supported themes. Remotes and Queue are separately approved visual designs; all other page redesigns remain unapproved. Zero-flash theme initialization remains required.
