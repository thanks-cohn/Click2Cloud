## Clarified product direction

Chutey's goal is to make the browser feel like a full-featured local file explorer, except that the files live across the internet and the user's connected cloud storage. Everything people intuitively expect to do with local files in a file explorer should, where technically supported and authorized, be possible with browser-accessible and cloud files: browse, select, multi-select, preview, drag, drop, copy, paste, organize, rename, and move files between folders, services, and compatible web applications.

**Core idea:** The browser becomes a file-explorer workspace, and the internet and cloud storage become the user's navigable file domain.

This is a long-term product direction, not a claim that every browser, website, clipboard action, or cloud provider already supports all these interactions.
