## Mandatory agent-native engineering standard — standing design contract
Build for human simplicity on the outside and machine-verifiable precision on the inside. Programmatic operability, observability, reproducibility and independent verification are design requirements, not afterthoughts. Every changed feature must identify its shared production entry point, validated inputs, authorization boundary, observable outputs/errors, invariants, and reproducible verification procedure. Human UI and agent calls must exercise the same underlying logic; do not create a parallel simplified test implementation. Prefer existing V3+1 interfaces, internal callable functions, service contracts, versioned manifests, deterministic state transitions, and structured events/receipts. Add scoped API operations only where justified; no public HTTP endpoint, extra permissions or bypass of user consent. Visual-only behavior may be inspected through actual DOM/computed styles and browser interaction rather than artificial production APIs.

### Reproducible lifecycle testing
Use isolated synthetic fixtures and existing test adapters to model expired auth, unavailable providers, delayed responses, interrupted uploads, browser/service-worker restarts, malformed configuration, large history and queue state, and long-lived accumulated state. Design new interfaces so future Reliability Lab can compose seeded scenarios, inspect results and replay failures without rewriting production engines. 100,000 History records and 10,000 queued job records are future scale-test targets, not a request for 10,000 live concurrent uploads, a new production simulator, or mandatory bulk stress infrastructure in 0.3.31. Keep permanent Reliability Lab separate; focused representative scale/failure regression cases for changed features belong here. Fault injection must be test-only and cannot affect real user data or unauthorized cloud resources.

### Per-feature evidence

3. Real-world execution: packaged installed Chrome behavior and explicitly authorized provider QA, with actual evidence and truthful blocked/skipped reporting.
